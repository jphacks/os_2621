# ひだまり (Hidamari)

> **心が疲れたとき、AIと対話し、同じ痛みを抱える仲間と安全につながる場所**  
> 気力ゼロでも、AIのエスコートで思考を整理し、同じ境遇の仲間と完全匿名・多重安全防壁のもとで分かち合えるピアサポートWebアプリケーション

---

## 製品概要

### 背景 (製品開発のきっかけ、課題等)
現代社会において、進路・人間関係・将来への不安から深い孤独感やメンタルヘルス不調を抱える若者・学生が増加しています。しかし、
1. **「専門の相談窓口はハードルが高く、説教や深刻化が怖くて連絡できない」**
2. **「既存のSNS（Xや掲示板など）では誹謗中傷、出会い目的の悪質ユーザー、個人情報流出、負の感情の共倒れ（増幅スパイラル）が起きやすい」**
3. **「AIチャットボットだけでは、人との温かい生のつながりや孤独感の解消には至らない」**

という3つの大きな壁が存在していました。

### 製品説明
**「ひだまり」**は、AIによる安心な傾聴・思考整理と、同じ悩みを抱えるピア（仲間）同士の安全な対話を滑らかに橋渡しするWebサービスです。  
ユーザーはログインや個人情報の入力なしで、今の気分のチェックインからAIとの対話をスタート。AIが相談内容から「分かち合いたい悩みの要約カード」を自動作成し、本人の明示的な同意のもとで、回復段階やエネルギーを考慮した最適な仲間とマッチング。完全匿名のテキストチャットおよび双方同意型のWebRTC音声通話（AIファシリテーターの見守り付き）を通じて、孤独感を和らげます。

### 特長
#### 1. 気力ゼロでも話せるAIエスコート & 自動要約生成
文章を論理的に組み立てる気力がない状態でも、AIが温かく傾聴して気持ちをほぐします。対話が落ち着いた段階で、他者と共有できる形に悩みを優しく要約。本人が確認・修正・共有判断を行う安心のオプトイン設計です。

#### 2. 多層防壁による徹底した安全設計 (Safety First)
- **多段危機検知（L1ルール + L2 LLM判定）**: 自傷・自殺念慮・虐待兆候を多段で判定。フェイルクローズド（判定不能時は安全側に倒してマッチング遮断）を徹底。
- **心に寄り添う受容型危機ケア（機械的打ち切りゼロ）**: 危機検知時も冷たく門前払いせず、受容メッセージ・その場での深呼吸ガイド（BreatheGuide）・無料公的相談窓口（#いのちSOSなど）・AI継続相談への温かい導線を提供。
- **年代別（6区分）マッチング & 未成年保護**: 中学生・高校生・大学生・20代・30代〜50代・60代以上の同一区分間でのみマッチングを許可し、世代間権力格差や未成年への悪質アプローチを防止。
- **共倒れ防止マッチング**: 類似度だけでなく「エネルギー度（活力）」を考慮し、エネルギー2以下の深刻状態同士のマッチングを回避。
- **個人情報自動マスキング (PII Guard)**: メールアドレス、電話番号、SNSのID、住所・学校名等をAI相談・要約・チャット全層で自動伏字化。
- **不正画面遷移ガード (FlowGuard)**: プロフィール登録やチェックインをスキップした不正アクセスを防止。

#### 3. 双方同意型ピアチャット & WebRTC音声通話 + AIファシリテーター
- テキストチャットに加え、双方が「通話する」と事前合意した場合のみ接続されるWebRTC P2P音声通話機能を搭載。
- 会話が途切れたり重い空気が続いた際には、AIファシリテーターが自然な問いかけや共感で場をサポート。
- 退出・ブロック・通報は全画面ヘッダーから1タップで即座に実行可能。

## 開発技術

### 活用した技術
#### フレームワーク・ライブラリ
- **フロントエンド / フルスタック**: Next.js 15 (App Router, React 19), TypeScript (Strict Mode)
- **スタイリング & UI**: Tailwind CSS, shadcn/ui, Lucide Icons
- **リアルタイム通信 / 音声通話**: WebRTC (Peer-to-Peer Audio), Supabase Realtime Signaling
- **テストフレームワーク**: Vitest, React Testing Library (全34テストスイート・175テストケース完備)

#### バックエンド / データベース
- **Supabase**: 
  - 匿名認証 (Anonymous Auth)
  - PostgreSQL (Row Level Security / RLSによる厳格なアクセス制御)
  - Realtime (メッセージングおよびWebRTCシグナリング)

#### AI / LLM
- **マルチLLMフォールバックアーキテクチャ**:
  - **Anthropic Claude 3.5 Sonnet / 3.5 Haiku**: 高度な傾聴・感情要約・高精度危機判定
  - **Google Gemini 2.5 Flash / Flash Lite**: 無料枠対応・高速ストリーミング・LLM Provider抽象レイヤーによる柔軟な切り替え

## 独自技術・こだわり

### ハッカソンで開発した独自機能・技術
1. **多層危機検知 & 受容型危機ケアエンジン (`lib/safety/`)**
   - 表現のゆらぎや遠回しな自殺・自傷念慮を確実に捉えるL1（正規表現・形態素）＋ L2（LLM文脈判定）。
   - 危機検知時にも「遮断されて見捨てられた」という絶望を与えないよう、対話を維持しながら安心できる公的窓口へと対話的に誘導するケアプロンプトとUI。
2. **共倒れ防止 & 年代別セーフティマッチングアルゴリズム (`lib/matching/`)**
   - 単なるベクトルの近さではなく、話したい度合・エネルギー・回復段階・年齢層を総合評価する独自の適合度計算ロジック。
3. **双方同意型WebRTC音声通話 & AIファシリテーター (`lib/webrtc/`, `lib/facilitator/`)**
   - 匿名性を保ちながらブラウザ間P2Pで通話を実現。AI司会者が開始時のアイスブレイクや会話の沈黙・偏りをリアルタイム検知して助け舟を出す仕組み。
4. **不正遷移防止ステートガード (`components/flow-guard.tsx`)**
   - クライアント側・サーバー側の多重セッション検証により、前提条件を満たさないURL直接叩きを防止し、自然で安全なステップバイステップ体験を保証。

## デモ手順・体験ガイド

リポジトリをクローンしてすぐにローカルまたはVercel上で体験できます。

```bash
# 依存パッケージのインストール
npm install

# 環境変数の設定 (Gemini APIキーがあればすぐに動かせます)
cp .env.example .env.local

# 開発サーバー起動
npm run dev
```

1. **トップ画面 (`/`)**: 「匿名ではじめる」をクリック（個人情報・パスワード不要）。
2. **気分チェックイン (`/checkin`)**: 今の気分とエネルギーを直感的に選択。
3. **AI相談ルーム (`/consult`)**: AIが優しくお話を伺います。話がまとまったら「話を整理する」をクリック。
4. **要約の確認・共有 (`/summary`)**: AIが作った要約カードを確認・編集し、「仲間を探す」を選択。
5. **マッチング候補 (`/candidates`)**: 同年代・適切なエネルギーバランスの候補一覧からリクエストを送信。
6. **ピアチャットルーム (`/rooms/...`)**: マッチング成立後、安心のテキストチャットおよび双方同意型音声通話を体験いただけます。
